# 上电与闭锁验证计划

> [!warning] 当前状态
> 本文仅为测试计划，所有测试均未执行。样机版本、输入范围、脉冲协议、负载与允许的最大停机时间尚未确认。不得把理论时间常数或一次继电器吸合作为安全功能验证通过。

## 先决条件

- [ ] 确认PCB与当前三页原理图一致，记录板号、版本、照片和实装MCU丝印。
- [ ] 完成[[项目/03 脉冲急停主板_copy/器件参数与BOM一致性核对]]中P0相关阻值和R65状态确认。
- [ ] 确认RELAY_VOLT到PC0的用途和保护边界；在此之前不向该节点施加5V测试电压。
- [ ] 明确12V和18V允许范围、CX回路、BS_IN幅值/频率/占空比、线缆和输出负载。
- [ ] 明确允许响应时间、故障后复位策略、上电是否允许自动吸合，以及最终判定依据。
- [ ] 使用可调限流电源、合适的隔离/差分测量和假负载；首次测试不接真实危险运动机构。

GND、GND1、GND2、CAN1_GND、CAN2_GND是不同网络，18VG与GND2之间还有元件。普通示波器各通道地夹通常共地；必须核对仪器接地，使用额定值适用的差分或隔离方法，避免把这些地经仪器短接。

## 闭锁故障矩阵

以下每项均记录输入变化时刻、两路许可、线圈电流、全部接点状态及恢复方式。允许响应时间尚未提供，测试报告不得提前填写“通过”。

| 场景 | 需要记录的行为 | 结果 |
| --- | --- | --- |
| 有效脉冲的幅值/频率/占空比上下边界 | 吸合条件、裕量和误释放 | 未执行 |
| 脉冲突然消失、卡高、卡低 | 从故障出现到线圈释放及接点变化的时间 | 未执行 |
| BS_IN断线、经确认的受限短路 | 是否释放，恢复后是否自动吸合 | 未执行 |
| 12V掉电、18V掉电和不同上电顺序 | 两路许可及反馈是否反灌，输出默认状态 | 未执行 |
| MCU复位、看门狗复位、程序停止 | 硬件许可、反馈和输出的关联 | 未执行 |
| 单路许可丢失或保持有效 | 另一支路是否能按要求使线圈释放 | 未执行 |
| 电源边界、温度边界、连续工作 | 光耦余量、PTC/LDO热状态和继电器吸合/释放 | 未执行 |
| 接点故障与外部负载异常 | 是否存在诊断覆盖、实际接点是否可观测 | 未执行 |

故障注入需先明确电流、电压、器件额定值与可恢复方式；不直接短接电源、不对未知引脚强灌电压。线圈反馈不等同于接点焊死检测，不能据此推断完整诊断覆盖。
