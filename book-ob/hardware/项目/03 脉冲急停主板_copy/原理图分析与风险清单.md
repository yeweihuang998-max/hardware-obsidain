# 原理图分析与风险清单

## 结论与证据等级

已核实内容是导出文件中的连接和属性，以及下载手册明确给出的参数。电压、电流和时序推导均属理论分析，尚无样机实测。页号均指本地PDF物理页。

| 优先级 | 项目 | 发现 |
| --- | --- | --- |
| P0 | RELAY_VOLT到PC0 | 约5V节点直连MCU，无分压；作为ADC使用时量程不匹配 |
| P0 | 继电器驱动 | 两只光敏三极管串联直接带线圈，LED驱动和线圈电压余量没有保证 |
| P0 | BOM一致性 | 多处图面值、厂家型号与装配注释冲突，不能直接用于生产 |
| P1 | LM334 | 6.8Ω设置约9.96mA，贴近10mA绝对最大值 |
| P1 | MCU的VCAP | 两只各1µF，已查手册给出2×2.2µF |
| P1 | CAN | 外部接口名与片内CAN实例交叉，且RXD约5V，需核对版本和固件 |
| P1 | 电源与保护 | PTC、电源模块最小负载、LDO发热和TVS钳位需联合预算 |
| P2 | 文档 | 看门狗时间为近似，图框和部分修改注释未闭环 |

P0表示先解决或证明边界，P1表示设计验证必须闭环，P2表示文档和维护问题；这不是认证等级。

## 1. 整体架构与电源域

- 12V输入经保护和LMR33630降至约5V，再经B0505S隔离模块得到5V1，AMS1117产生3.3V供MCU、W5500和OLED。
- MCU连接SPI以太网、双路隔离CAN、按键、显示与CX查询收发。
- 18V域供CX模拟电路和闭锁检测。BS_IN的直流及交流变化分别检测，两路光耦串联许可继电器。

| 地网络 | 对应电路 |
| --- | --- |
| GND | 12V输入、降压器和隔离模块一次侧 |
| GND1 | MCU、以太网、5V1、3.3V及继电器线圈 |
| GND2 | 18V、CX和闭锁模拟检测 |
| CAN1_GND、CAN2_GND | 各自CAN收发器的总线隔离侧 |

网表中这些地不同，未见直接等电位连接。这仅证明网络分离，不能证明PCB间隙、耐压或系统隔离合格。18VG与GND2之间还串有D19和L2，测量参考地需区分。

## 2. 电源

### 12V到逻辑电源

CN2.2→L7→F9→D7/D8→VCC→U5→L1→F2→+5V。按R6=100kΩ、R10=24.9kΩ及FB参考1V计算，反馈取样点约为1×(1+100/24.9)=5.016V，F2和走线会产生额外压降。依据LMR33630手册的FB规格及原理图第2页。

Q1/Q2与U3/U4组成两条可控硅过压短路保护支路。实际触发电压、门极电流、源限流与F2动作配合需要测试，不能仅凭稳压管标称值确定保护门限。

U13实际选用EVISUN易成B0505S-3WR2，手册注明隔离非稳压输出，5V/600mA，最小负载栏60mA。不能用其他厂家同名产品参数替代。+5V1同时供CAN、继电器和LDO，应测轻载、启动及线圈切换时是否仍满足CA-IS3062的4.5～5.5V推荐范围。

U11为永裕泰AMS1117-3.3，选用SOT-89。热耗散约为(V5V1−3.3)×I3.3V。示例5V、200mA对应0.34W；200mA仅为计算示例，实际整板负载未测。

F9的25°C保持电流为200mA，因此U5标称3A不代表整板电源链能提供3A。需按W5500工作、MCU负载、双CAN主动态、OLED和继电器同时工作的情形预算。

### 18V模拟域

CN2.14→D18→L2→F7→+18V，回路经GND2、L2、D19回CN2.13。F7=SMD0603-001-60：手册第2页Ihold=10mA、Itrip=50mA、Ri最低15Ω、动作后最大恢复电阻100Ω。

查询发送导通且具有回路时，LM334支路本身约10mA，此外还有运放和光耦LED负载。必须核算各状态的总电流、压降和温度降额。PTC的Ihold不是恒流限制，也不表示超过10mA立即断开。

D3/D17是SMAJ26CA。26V是反向工作电压档位，不是浪涌钳位电压；应将其钳位曲线、脉冲条件和布局寄生与被保护芯片最大值比较。

## 3. MCU、看门狗与以太网

U2=APM32F405RGT6；X1为8MHz无源晶体；SPI1连W5500；PB10/PB11连I2C OLED；PC1/PC2/PC3连按键；H2为SWD。

### VCAP电容

U2.31的VCAP_1接C31=1µF，U2.47的VCAP_2接C30=1µF。C14/C15虽然是2.2µF，但它们接在3.3V电源轨，不能替代VCAP电容。A/C版手册供电图均标2×2.2µF，C版见PDF第66页。需按实装芯片版本核对电容、ESR和布局。

### 看门狗

TPL5010的DONE接PA1，RSTn接NRST，定时电阻R14=10kΩ。TI手册PDF第13页给出8s对应约10.18kΩ；按该页5～10s分段拟合，10kΩ约7.63s。图面“8s”为近似值，需结合容差和固件喂狗时序验证。

### W5500

- EXRES1要求12.4kΩ、±1%到模拟地。R19图面12.4K，但采购型号是10kΩ，应先统一。依据W5500 V1.1.0的EXRES1引脚说明。
- X3提供25MHz外部时钟到XI/CLKIN，XO悬空与外部时钟方式一致；晶振使能脚悬空的行为仍需按该晶振规格核对。
- VBG悬空、1V2O接10nF与手册一致，不属于漏接。
- 网口中心抽头、屏蔽、ESD与差分阻抗还需PCB核查。

## 4. CAN

| 物理接口 | 网名及收发器 | MCU引脚 | 片内功能 |
| --- | --- | --- | --- |
| CN2.3/4 | CAN1，U1 | PB5/PB6 | CAN2_RX/TX |
| CN2.5/6 | CAN2，U10 | PA11/PA12 | CAN1_RX/TX |

这是接口命名与片内编号交叉，不自动表示接错。固件需按引脚配置正确实例。原图“外部CAN 5K、内部CAN 250K”是标注，未读取固件确认实际波特率。

CA-IS3062的逻辑侧5V供电，RXD高电平典型4.8～5V，见其PDF第8页。A版MCU手册PDF第26页把PB5的I/O结构列为“-”，C版第28页列为5T，因此需先确认芯片版本。PA11/PA12在所查手册列5T，但仍需核对数字模式、掉电顺序和注入限制。

H5的1-2闭合接入CAN1的120Ω终端，H6的1-2闭合接入CAN2终端。终端是否安装取决于总线位置，不能每个节点都默认安装。

## 5. CX查询

- PA10→R13=330Ω→U16 LED；光敏侧由LM334经F3、U16、D1向CX注入电流。
- PB0→R45=330Ω→U19，配合Q6、R38/R40及D20/R35形成CX下拉支路。
- 发送协议和两个GPIO是否允许同时有效，尚未读取固件确认。

### LM334余量

ST手册第3页规定25°C下Iset=67.7mV/Rset。R30=6.8Ω时约9.956mA，已贴近第2页10mA绝对最大设置电流。R30公差±5%，6.46Ω时理论约10.48mA；电流还随绝对温度增加。应根据目标查询电流重算阻值、功耗和全温度余量，不能以25°C名义值略小于10mA判定合格。

### 接收阈值

CX经R43=1MΩ到U15A同相端；R44/R12产生反相端参考；输出驱动U18，MCU侧由R41上拉3.3V。按图面200kΩ/100kΩ，参考约为18V的1/3即6V；若R12按绑定型号15kΩ装配，参考约1.26V。两者差异很大，需确认实际意图。

U15为双运放，但网表只见A通道，B通道5/6/7脚未出现，需核查未用通道处理。

## 6. 闭锁检测

### 直流支路

BS_IN经F10后，R49～R52四只470kΩ构成低频约1/4分压，C2/C59/C60滤波。U20B同相增益为1+R48/R31。R31=39kΩ，R48只写“78”无单位且绑定39kΩ型号，增益意图不确定，不能擅自改成78kΩ。

BS_DSIG_CHK经R42=100kΩ、C72=100nF形成约10ms滤波，U20C与参考比较后驱动U8。

### 脉冲/交流支路

BS_IN经C67交流耦合，R59回零，D4半波整流，R60/R61/C68滤波，U21A跟随；U21B再跟随，经R54/R58和C64/C65/C66平滑到BS_ASIG_CHK。

按图面，R54/R58各51kΩ，低频衰减约1/2；并联电容总计23.1µF，理想低阻驱动下时间常数约(51kΩ∥51kΩ)×23.1µF=0.589s，前级还存在约51ms滤波。**这不是实测停机时间**，实际释放时间由门限、脉冲参数和各级充放电共同决定。

U20D增益为1+82kΩ/10kΩ=9.2；U20A与参考比较后驱动U7。按R83=200kΩ、R84=20kΩ，18V时参考约1.636V，等效BS_ASIG_CHK门限约0.178V，忽略失调和输出限制。若按两个100kΩ型号采购，参考变9V。

### 两路许可与继电器

U7/U8光敏三极管串联在线圈低端，两路都有效才有吸合电流通路，构成硬件AND许可。是否满足断线、静态卡死和掉电的安全动作，需要系统需求及故障测试；不能据此宣称双通道安全冗余或安全等级。

OMRON手册第2页：5V线圈约237Ω、21.1mA，单稳态型号在23°C的保证吸合门限为额定80%即4V。

假定运放输出能到18V、光耦LED压降1.15V、R66/R69=4.7kΩ，LED电流约3.59mA，这是乐观估计。UMW的GB档最小CTR=100%是在IF=5mA、VCE=5V下测得，不能保证3.6mA输入时在低饱和压降下驱动约20mA线圈。两只光敏三极管串联不会增加可用电流。

R65=51Ω仍在网表/BOM中。即便乐观假设两只光耦各压降0.2V，线圈电压约为(5−0.4)×237/(237+51)=3.785V，低于4V保证吸合界限；实际约20mA时的饱和压降也未获保证。

原图已有“这两个电阻太大，导致光耦不能完全导通”和R65旁“去掉”注释。需确认正式修改方案；R65直接不贴会使线圈开路，若意图旁路必须明确短接/0Ω装配，不能机械按文字删掉。可评估光耦传递逻辑、另用晶体管/MOSFET带线圈，但要保留两路许可及所需故障行为。本轮未改图。

详见[[知识/模拟电路/光耦直接驱动继电器的电流预算]]。

### PC0电压反馈

RELAY_VOLT连接D21/D22阳极、R65、U7集电极和U2.8(PC0)，没有分压与串联限流。驱动关闭时会经线圈和R65靠近+5V1。

C版手册将PC0列5T，因此不能笼统断言5V一定损坏引脚。但若用作ADC，正常转换范围为0～VREF+，在3.3V参考下5V超量程。应确认固件用途、模拟模式保护、5V1轻载上升及3.3V掉电时序，评估分压、滤波、限流与保护方案。

## 7. 装配与文档

- 全部234个条目均为Add into BOM=yes，包括图面标NC的R18/R28/R55/C61、测试点和带“去掉”注释的R65。普通导出清单不是已批准的装配BOM。
- 第1页图框保留其他产品名称和2023年信息，和当前工程及2026年图页元数据不一致，应确认是否沿用模板；不能据此确认产品型号、批准版本或本安认证。
- 485_TXD2/RXD2、IN_1/2、KEYVAL_A*等部分网络只有MCU一端，需确认预留/遗留用途，不能仅凭网名声称板上有RS-485收发器。
